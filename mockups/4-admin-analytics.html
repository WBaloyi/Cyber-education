Suggestion 4

Admin analytics and export

Help the admin see how full each quarter is and which courses are growing, then export the list.

Why add it
  • The dashboard shows enrollments as one long table, which is hard to plan capacity from.
  • CSV export makes it easy to email class lists to lecturers.
  • Build: a few GROUP BY queries on enrollments. Charts can be plain HTML/CSS (as here) or Chart.js.
