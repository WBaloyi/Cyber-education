Cyber Education

Suggested features

Four features that build on what the app already does (courses, quarterly start dates, enrollment, testimonials, admin). Each one has three mockups showing different ways it could look.

Suggestion 1

Student portal: "My learning"

Learners sign in with their email to see their enrollments, track progress, change their start date or cancel. Today they get one confirmation message and nothing after it.

See 3 mockups

Suggestion 2

Waitlist and start-date calendar

When a quarter is full, people can join a waitlist instead of leaving. Adds a quarter-by-quarter calendar of all courses and an "Add to calendar" confirmation.

See 3 mockups

Suggestion 3

Course detail page

A page per course with a week-by-week syllabus, lecturer profile, fees, and reviews for that course. Courses are only shown as tiles right now.

See 3 mockups

Suggestion 4

Admin analytics and export

Charts of enrollments and fill rate per quarter, filters, and CSV export, so the admin can plan capacity rather than reading a raw table.

See 3 mockups
Smaller ideas worth adding too
  • Confirmation email after enrolling (Flask-Mail).
  • Let the admin edit courses and capacity from the dashboard instead of editing course-data.json.
  • Certificates (PDF) when a course is completed.
  • Dark mode toggle.
